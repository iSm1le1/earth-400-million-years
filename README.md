# 《地球的四亿年》

> 一个由真实板块重建数据、计算验证和科学证据共同驱动的可探索地球演化实验。
> 拖一根时间轴，从今天拖回四亿年前；你可以在地图上钉一个点——任何地方——
> 看它在四亿年里怎么跑遍全球。

**这是一份"接手说明"**，写给任何第一次打开这个文件夹的人（或 AI）。
**注意：项目的原始方案书不在本目录**，本文的"任务约束/验收标准"两节是从
代码、报告与说明文档里反推出来的（每条都标了出处），如有出入以原始方案书为准。

---

## 一、这个项目是什么

一个**完全离线、可交互的全球板块重建可视化**：把 EarthByte Merdith et al. (2021)
的板块重建模型在 pygplates 里跑成 401 个时间切片（0–400 Ma，每 1 Ma 一帧），
再用 canvas 实时画成一张可拖动时间轴的地图。所有大陆轮廓都不是画的，是模型算出来的。

**核心主张**：你出数据，代码出画面。任何一条结论都要能回到计算证据（`checks.json`）
或文献来源（`CITATION.md`）。

## 三、任务约束（做的时候被要求遵守的）

1. **数据必须真实可核**：用公开的板块重建模型，**不许手工编坐标**，不许手画大陆。
   所有 `land` 顶点都来自 pygplates 重建。（`report.md` §1）
2. **零图片**：不许生成任何位图，地图必须由前端 canvas 实时绘制。（`report.md` 说
   "方案书明令禁止"）
3. **运行时不调 API、不联网**：全部是静态文件，页面打开后离线可用，无 API Key、
   无后端。（`Demo说明.md` §四）
4. **确定性构建**：同环境重跑，`earth.json` 字节一致（没有随机数、没有时间戳、
   浮点路径固定）。（`report.md` §7）
5. **页面不能卡**：每片顶点数控制在 1.1 万–2.2 万（原方案书是 3000–6000，
   后因"要更细腻"放宽）。（`build.py` 常量注释）
6. **六项硬自检必须全过**（见下）。（`report.md` §3）
7. **叙事与数据一致**：事件文案里的数字全部由 `build.py` 现算注入，不许硬编码；
   文案严格区分"模型数字"与"文献解释"，不抢跑。（`report.md` §4）

## 四、验收标准

**六项硬自检**（`checks.json` 有全部原始数字）：

| # | 检查 | 阈值 | 当前实测 |
|---|---|---|---|
| ① | 陆地面积稳定 | 面积中位数 ±15% | 中位 138.98e6 km²，最大偏差 **4.91%** |
| ② | 南极位置 | 0–35 Ma 质心 < 60°S；全程不近赤道 | 最北质心 **-75.7°S** |
| ③ | 速度上限 | 每步 ≤25 cm/yr | 最大 **18.9 cm/yr** |
| ④ | 顶点数平滑 | 每片 11000–22000；相邻片不跳变 | **14543–15235**，最大比值 1.02 |
| ⑤ | 已知事实 | 200 Ma 潘吉亚连通率 >80% 等四项断言 | 99.9%，四项全过 |
| ⑥ | 反子午线 | 普通边经度差 <180° | 最大 176.57° |

**附加**：0 Ma 现代海岸地标核对（10 个地标到最近海岸 0.0–32.2 km，阈值 <50 km）。

**严格构建检查 15 项**（`build.py` 末尾，任一不过即终止）：JSON 可解析、无重复单位、
无 `None`、无未替换占位符、事件有 evidence 且在 1 Ma 网格上、按 400→0 排序、
401 片时间为 1i、顶点数与实际一致且在预算内、marker 轨迹长 401 且 track[0]=现代坐标、
逐片 metrics 齐全、地标核对通过、渲染字段齐全、最终数据无 >180° 边、无自交环。

当前状态：**六项自检全过，strict 15/15**。

## 五、怎么跑

```bash
cd 地球的四亿年
.venv/bin/python build.py          # 生成 earth.json / checks.json（约 40 分钟，确定性）
.venv/bin/python make_preview.py   # 生成 preview.html（把数据内联进去）
# 然后双击 preview.html 即可，无需联网
```

- `data/` 已随包提供模型，**日常重跑完全不联网**（缺了才自动下载）。
- 环境：Python 3.13 + pygplates 1.0.0 + numpy + shapely（仓库内 `.venv/`）。
- 本版 md5：`earth.json` = `9956b0e5bfaacc75aadf3b982bc57b69`，
  `checks.json` = `fc7061ba5bae4a34cfca8383d8ed4633`。

## 八、已知限制（诚实清单，详见 `report.md` §5）

1. 400 Ma 中国陆块**低纬但不在南半球**（模型给出上海 +10.1°N、拉萨 -19.9°S），
   数据按原样输出，叙事不含糊。
2. 250 Ma 附近是两套子模型的拼接界面，局部速度台阶是边界效应，不是地质速率。
3. 古地磁参考架下**古代经度弱约束**：轨迹的纬度可信、经度只能当"大致在哪个象限"。
4. 简化把细齿海岸抹平，0 Ma 陆地面积比真实值低约 3%。
5. 源海岸线文件混装了 10 种要素类型，其中 `Basin`（海盆）/ `IslandArc`（岛弧）
   **不是陆地**，已整体剔除；代价是**冰岛**等一批小岛不再出现（源模型本来就没
   把它们当陆块要素）。
6. 极点缝合顶点是渲染用的合成几何。
7. 模型结果不是唯一的地球历史解释；事件文案严格区分"模型数字"与"文献解释"。
